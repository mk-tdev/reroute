# Three-minute demo script

Record on a phone-sized browser window (390 × 844) with `npm start` running. Start from a fresh island (*Menu → Start a fresh island*).

| Time | Show | Say |
| --- | --- | --- |
| 0:00 | The island, first-run onboarding | "Most habit apps reward perfect streaks. Real life doesn't work that way: meetings run late, it's 42 degrees outside, energy dips. ReRoute is built for the moment a plan breaks." |
| 0:15 | Pick 3 days a week. Set plans: *time → One flight, easy pace*, *weather → The sheltered loop* | "First, two quick decisions: a realistic weekly goal, and a backup for each common obstacle. If-then plans like these are one of the best-supported techniques in behavior change." |
| 0:35 | Turn on weather and AI notes | "Both helpers are optional, and the screen says exactly what each one sends." |
| 0:45 | Tap **Fresh air**, watch the walk, then **Plans changed → Weather changed** | "I was going to walk outside. It's too hot." |
| 0:55 | Detour card: the user's plan first, the reasons, the AI note | "ReRoute ranks options that still work. My own plan comes first, and it tells me why: it's hot outside, so this stays indoors. The note is written by Claude, but Claude never picks the activity. A rule engine does that, and every note is checked before I see it." |
| 1:15 | **Take this way → Let's go → Preview completion**. Mist clears, bridge appears | "Taking a detour isn't failure. It literally builds a bridge on my island." |
| 1:35 | *Menu → Demo tools → Skip ahead three days* | "Now say I disappear for a few days." |
| 1:45 | Welcome-back sheet | "No broken streak, no guilt. Welcome back, here's a two-minute way in. Coming back is the skill we celebrate." |
| 2:00 | Complete it; "You came back. That's the skill." *My journey*: week strip, comebacks tile | "Comebacks are the number we track most." |
| 2:15 | *Settings → العربية* | "Fully available in Arabic, right to left." |
| 2:25 | Open `/pilot.html` | "For a workplace or community pilot, organisers see only aggregates: return within 7 days of a lapse, weeks meeting goal, which detours help. This is synthetic demo data, and it's labelled that way." |
| 2:45 | Back to the island | "ReRoute: a small step, a new path, and a way back. Next, a four-week pilot against a fixed-plan version." |
